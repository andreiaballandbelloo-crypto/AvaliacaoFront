Sobre


O HTML serve para construir a estrutura e o conteúdo de uma página web. HTML não é uma linguagem de programação. Ele não diz como a página deve ficar bonita. Isso é trabalho do CSS.
O CSS serve para estilizar o HTML: mudar cores, fontes, tamanhos, espaçamentos, posição, bordas, fundos e adaptar a página para diferentes tamanhos de tela. Você escolhe um elemento do HTML e estiliza.
O JavaScript serve para colocar interatividade na tela, como clicar em botões, mostrar mensagens de alerta e permitir que o usuário interaja com a página.
